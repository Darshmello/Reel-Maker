How a film gets made

  1. 01

    Prompt

    One what-if question. Your CLI agent writes the title, three escalating acts, counters and a punchline.

  2. 02

    Voice

    edge-tts reads the script, paced so the narration lands 1.6 s before the cut. Or drop in your own recording.

  3. 03

    Align

    faster-whisper finds when every word is said and maps it back to the script's spelling.

  4. 04

    Cue

    Every cut, label and effect is timed from an anchor phrase, so a new voiceover re-times the whole film.

  5. 05

    Render

    Remotion draws the three.js city frame by frame. Seeded and deterministic: no clocks, no randomness.

  6. 06

    Master + QA

    −14 LUFS, true peak under −1.5 dBTP, then 16 checks: safe zones, cover, determinism.

    Docs / Getting started

    Getting started

    Six steps from a fresh Windows machine to your first rendered Reel. Commands are PowerShell; run them one at a time. Writing the acts uses a coding agent you are already logged into (Claude Code or opencode): no API keys.

    1. Install the tools

      Node.js runs the studio and the renderer, Python runs the voice and alignment, FFmpeg masters the audio. Skip anything you already have.

      winget install OpenJS.NodeJS.LTS
winget install Python.Python.3.12
winget install Gyan.FFmpeg
winget install Git.Git

      Open a new terminal so the new commands are on PATH, then check:

      node -v; py -3.12 --version; ffmpeg -version; git --version

    2. Get the code

      git clone https://github.com/Darshmello/Reel-Maker.git
cd Reel-Maker
npm ci

      npm ci installs the exact pinned versions from package-lock.json (Remotion, three.js, React).

    3. Set up the Python tools

      py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r scripts/requirements.txt

      This installs edge-tts (the placeholder voice), faster-whisper (word timing) and numpy/scipy (the sound mix). The first alignment downloads a ~250 MB speech model once.

    4. Connect a writer agent

      The agent turns your one-line question into the full spec: title, three acts, counters and a punchline. Pick one; you can switch any time on the Create page.

      1. Install. The native installer (recommended):

      irm https://claude.ai/install.ps1 | iex

      or with npm:

      npm install -g @anthropic-ai/claude-code

      2. Log in. Run it once and sign in with your Claude account in the browser window it opens.

      claude

      3. Test it headless. This is exactly how the studio calls it:

      claude -p "Reply with OK"

      The studio runs claude -p with tools, MCP servers and settings turned off, in an empty temp folder, using the Sonnet model. It can't touch your files. Each build is one or two short requests on your own plan.

      1. Install.

      npm install -g @opencode/cli

      2. Choose a model provider. opencode ships with free models; to use your own subscription, log in to a provider:

      opencode auth login

      3. Test it headless.

      opencode run "Reply with OK"

      The studio writes the brief to a temp file and runs opencode run -f brief.md … in that temp folder, then reads the JSON from the reply. Pick a model with -m provider/model by editing the command under Connect an agent.

      Any CLI that takes a prompt and prints text works: Codex CLI and Gemini CLI are preset, and you can add your own command. See Connect an agent.

      No agent at all? The Offline draft writer fills in a rough spec from keywords so you can still edit and render.

    5. Start the studio

      npm run studio

      Then open http://127.0.0.1:4321. The server only listens on this computer and only answers its own page. The box at the top of this guide turns green for each agent it finds.

    6. Make your first film

      Go to Create, type a question and press Build the acts. Read what the agent wrote, change anything you like (the preview shows where text lands inside the Reels safe zones), then Save and render. A render takes about five minutes and ends with 16 QA checks. The film lands in out\<slug>.mp4 and on the Films page.

      Open Create

    Prefer not to write a prompt?

    Docs / Connect an agent

    Connect an agent

    A writer is any command-line agent you are already logged into. The studio sends it a brief (the rules of the format, the act library, a worked example and your question) and reads one JSON spec back. Nothing here uses an API key.

    How a command runs

    • It runs in a fresh, empty temp folder that is deleted afterwards.
    • {promptFile} in the command becomes the path of a file holding the brief. Without it, the brief is piped to the command's stdin.
    • The first JSON object in the output with an acts field is taken as the spec. If it fails the checks, the agent gets one retry with the errors listed.
    • If the agent is missing or fails, the Offline draft writer is used and the Create page says why.

    Docs / Command line

    Command line

    Everything the studio does is a script you can run yourself.

    Render one film

    powershell -ExecutionPolicy Bypass -File scripts/render.ps1 <slug>

    Add -KeepVo to reuse the last voiceover, or -SkipRender to re-master an existing render.

    Render everything

    powershell -ExecutionPolicy Bypass -File scripts/batch.ps1
powershell -ExecutionPolicy Bypass -File scripts/batch.ps1 -Only snow-month,rain-40-days

    QA only

    .venv\Scripts\python scripts/qa.py <slug>

    Use your own voice

    Record the script and save it as public/vo/<slug>.user.wav (or .mp3/.m4a). The next render aligns to it and re-times every cut.

    Pipeline

    1. make_vo.py: placeholder voice, paced to end 1.6 s before the cut
    2. align.py: word timings → out/<slug>/words.json
    3. dump-events.mjs: resolves every cue with src/film/beats.ts
    4. mix.py: voice, ducked music bed and effects
    5. Remotion render → two-pass loudnorm → +faststart
    6. qa.py: 16 checks

    Docs / Troubleshooting

    Troubleshooting

    “cue … is said 2 times”
    An anchor phrase appears twice in the script. Make it longer (three words) or reword one line.
    “script is N words; 36 s fits about M”
    The voice can't fit. Cut words; the voice speeds up at most 24% before giving up.
    The writer fell back to Offline draft
    The note under the prompt says why. Run the agent's test command from Getting started in a terminal; it usually needs a login.
    opencode is slow
    Free models can take a minute or more. Give it a faster model with -m in a custom command.
    QA fails “true peak”
    Re-master without re-rendering: scripts/render.ps1 <slug> -SkipRender.
    The page is blank
    The studio server stopped. Run npm run studio again.

    Reel Studio runs locally on 127.0.0.1. Nothing is uploaded or posted. Voice is an edge-tts placeholder; music and effects are synthesized.
