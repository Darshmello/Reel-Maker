The pipeline

Six steps, one command

  1. 01

    Write

    A spec: the question, three acts, an ending. Each act picks one change from the library.

  2. 02

    Voice

    edge-tts reads the script, paced so the narration lands 1.6 s before the cut. Or drop in your own recording.

  3. 03

    Align

    faster-whisper finds when every word is said, then maps it back to the script's spelling.

  4. 04

    Cue

    Every cut, label and effect is timed from an anchor phrase, so a new voiceover re-times the whole film.

  5. 05

    Render

    Remotion draws the three.js city frame by frame. Seeded, deterministic, no clocks.

  6. 06

    Master + QA

    Two-pass loudnorm to −14 LUFS, true peak under −1.5 dBTP, then 16 checks: safe zones, cover, determinism.
